The budget plans arrive in a folder, all using the same spreadsheet template. The checker opens each one, takes out the numbers and does the careful checks first. Do the months add up to the year? Do the totals match?

Then it does the useful part: it compares each plan with the previous year's results, product by product, and notes anything worth discussing, along with a suggested question.

Each review is a Word document, so it can be edited and talked through together. There's also a one-page overview of all the plans.

The rule written at the top of its instructions: **this helps people decide. It isn't the decision.** Every figure is marked as provisional until a person has checked it.
