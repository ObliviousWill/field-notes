The first version made a two-page PDF each morning. Page one covered yesterday. Page two compared this week with last week.

To get there I wrote down, in plain English, exactly how the report should be put together: which systems to look in, which numbers to take, what counts as "this week", and what to compare each number against. Claude follows that written guide every time. It's called a skill, and it's really just a very precise set of instructions.

Two rules went in on day one:

- **Never make up a number.** If a system doesn't answer, the report carries on without it and says what's missing.
- **Label early figures as provisional.** Any figure that hasn't been confirmed yet carries a note saying so.

It worked well. The next step was making it easier for others to see.
