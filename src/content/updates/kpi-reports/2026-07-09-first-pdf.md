The first version made a two-page PDF each morning. Page one covered yesterday. Page two compared this week with last week.

To get there I wrote down, in plain English, exactly what a person would do: which systems to open, which numbers to take, what counts as "this week", and what to compare each number against. Claude follows that written guide every time. It's called a skill, and it's really just a very precise set of instructions.

Two rules went in on day one:

- **Never make up a number.** If a system doesn't answer, the report carries on without it and says what's missing.
- **Mark early figures as provisional.** One of the systems it reads is new and still being tested, so its numbers get a warning label.

It worked. The problem was where the PDF ended up: in my own chat, where nobody else could see it.
